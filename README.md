# 星焰跃界

`星焰跃界` 是一个基于 `Python + Pygame` 开发的 2D 平台闯关课程项目。它在本地课程作业版本基础上继续扩展，重点强化了关卡设计、事件系统、Boss 战、技能成长和界面表现。

这个版本不只是“能跑能跳”的原型，而是一个包含三关流程、遭遇战、独立 Boss 房、强化掉落与 HUD 交互的完整小游戏作品。

## 项目亮点

- 三关递进式关卡结构：热身关、机关联动关、Boss 终局关
- `levels.json` 数据驱动关卡，平台、敌人、触发器和事件均可配置
- 遭遇战系统：封门、刷怪、解锁、波次推进
- 第三关独立 Boss 场景，带多阶段血条和多种攻击机制
- 技能与成长系统：火球能力、永久强化掉落、宠物支援
- 更完整的 HUD、帮助面板、暂停界面、检查点与结算流程

## 当前玩法内容

### 第一关：机关热身场

- 让玩家熟悉基础移动、跳跃与火球攻击
- 引入动态平台、塌陷平台、假墙和检查点
- 用小型封门战收尾，建立关卡节奏

### 第二关：联动试炼井

- 强调上下分路与机关联动
- 加入多段遭遇战与中途增援
- 通过风险与收益差异提升探索感

### 第三关：星焰 Boss 房

- 玩家会进入单独的 Boss 场景
- 场景封闭，击败 Boss 后才可离开
- Boss 具备飞行、多阶段攻击、召唤与环境压制等机制

## 操作说明

- `A / D` 或 `← / →`：左右移动
- `Space`：跳跃
- 空中再次跳跃：二段跳
- 二段跳后短按或长按跳跃：用于延展空中机动
- `W / ↑`：上瞄
- `F / J`：发射火球
- `H`：显示 / 隐藏帮助面板
- `P / Esc`：暂停 / 继续
- `R`：重开当前关卡
- `Enter`：开始游戏 / 重新开始

### 调试按键

以下按键用于课堂演示或测试，不建议作为正式玩法亮点展示：

- `U`：无敌开关
- `T`：立即击败当前 Boss

## 运行方式

### 环境要求

- Python 3.10 或更高版本
- `pygame`

### 安装依赖

```bash
pip install pygame
```

### 启动游戏

```bash
python main.py
```

### 冒烟测试

```bash
python main.py --smoke-test 180
```

程序会自动运行短时循环，用于确认窗口、资源和主流程可以正常启动。
